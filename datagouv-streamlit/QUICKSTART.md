# 🚀 Quick Start Guide

Get up and running in 60 seconds!

## Installation

```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/datagouv-dashboard-builder.git
cd datagouv-dashboard-builder

# Create virtual environment
python -m venv venv

# Activate (macOS/Linux)
source venv/bin/activate

# Activate (Windows)
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run app.py
```

## Usage

1. **Search**: Enter keywords to find datasets on data.gouv.fr
2. **Select**: Click "Select" on any dataset to load it
3. **Build**: Configure KPIs and charts in the Dashboard Builder
4. **Export**: Share your dashboard or download insights

## Features

- 🔍 Search 35,000+ datasets
- 📊 Auto-generate visualizations
- 🔎 View transparent SQL queries
- 📐 Drag-and-drop editor
