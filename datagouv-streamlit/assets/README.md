# Assets Folder

This folder contains static assets for the project.

## Contents

- `demo-screenshot.png` - Main dashboard preview image for README
- `logo.png` - Application logo (optional)
- `favicon.ico` - Browser favicon (optional)

## Demo Screenshot

To generate a demo screenshot:

1. Run the app locally: `streamlit run app.py`
2. Navigate to your dashboard
3. Use browser dev tools or a screenshot tool to capture the UI
4. Save as `demo-screenshot.png` in this folder
5. Recommended size: 1200x800px or 16:10 aspect ratio
